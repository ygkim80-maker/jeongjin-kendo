# 정진 검도

현재 개발 버전: **v2.0** (`package.json`: `2.0.0`).

v2 개선은 기존 게임의 `src/scene.js` 등 실제 실행 경로에 직접 반영합니다.
배포는 전용 저장소 `ygkim80-maker/jeongjin-kendo`의 `main`과 기존 운영 주소를 사용합니다.
`v2-demo.html`은 참고용 동작 장면이며 별도 운영 버전으로 관리하지 않습니다.

## 버전 관리

- **v1.0**: 현재 정진 검도의 기준 버전. 이후 작업은 이 버전에서 출발합니다.
- **v1.1, v1.2, …**: 기존 게임을 유지하면서 동작, 그래픽, UI 등을 개선하는 업데이트입니다.
- **v2.0**: 선수 모델이나 렌더링 방식 등 게임의 큰 틀을 바꾸는 개편입니다. 별도 검증 후 적용합니다.

릴리스 시 해당 버전의 소스를 Git 태그(`v1.0`, `v1.1` 등)로 남깁니다. 실험용 시범 모델은 승인을 받기 전까지 현행 게임에 적용하지 않습니다.
