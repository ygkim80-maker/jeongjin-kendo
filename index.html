FIRST STEPS

한 판을 만드는 방법

  1. ← / →로 후퇴·전진합니다. 일족일도가 타격 거리입니다.
  2. Space를 누르면 세메와 이리미가 자연스럽게 번갈아 나옵니다.
  3. W / S / D / A / Q로 큰머리·작은머리·손목·허리·찌름을 시도합니다.
  4. 1 또는 Shift는 방어, E / R은 중단·상단입니다.
  5. ← + W / S 퇴격머리, ← + A 퇴격허리, → + A 역허리입니다.
  6. Esc는 일시정지, C는 시점 변경입니다.
